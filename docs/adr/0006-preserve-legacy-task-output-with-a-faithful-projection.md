# Preserve legacy task output with a faithful projection

Keep the published task JSON/NDJSON representation as the default and add an explicitly selected, versioned projection of returned task facts. Correcting omitted-value defaults and exposing previously discarded facts in the default representation would change behavior relied on by machine clients; a separate projection trades an extra opt-in for compatibility, preserves raw object/array shapes, and leaves the human-only meaning of `--full` intact. Keep task resource selection separate from planner, review, and acknowledgement contracts so shared API response types do not silently alter their output.
