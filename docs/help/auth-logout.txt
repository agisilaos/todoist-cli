Usage:
  todoist auth logout

Flags:
  No command-specific flags.

Global flags:
  -h, --help             Show help without running the command
  --profile <name>      Select the credential profile
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Disables the selected profile and removes its stored credential. Does not revoke the token or unset TODOIST_TOKEN.
  If native cleanup fails, retry logout or use todoist auth repair.

Examples:
  todoist --profile work auth logout
