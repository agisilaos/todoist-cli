Usage:
  todoist comment update --id <id> --content <text>

Flags:
  --id <id>                         Comment ID
  --content <text>                  Comment content

Global flags:
  -h, --help             Show help without running the command
  -n, --dry-run          Preview without Todoist mutations (reads may occur)
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Find comment IDs with comment list; --content replaces the comment text literally.

Examples:
  todoist comment update --id 567 --content "Review complete"
