Usage:
  todoist comment delete --id <id>

Aliases: rm del

Flags:
  --id <id>                         ID

Global flags:
  -h, --help             Show help without running the command
  -n, --dry-run          Preview without Todoist mutations (reads may occur)
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Find comment IDs with comment list. Prompts in a terminal; --force confirms without prompting.

Examples:
  todoist comment delete --id 567 --dry-run
