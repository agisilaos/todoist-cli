Usage:
  todoist project delete --id <id>

Aliases: rm del

Flags:
  --id <id>                         ID

Global flags:
  -h, --help             Show help without running the command
  -n, --dry-run          Preview without Todoist mutations (reads may occur)
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Find the ID with project list. Prompts in a terminal; use --force to confirm without prompting.

Examples:
  todoist project delete --id 234 --dry-run
