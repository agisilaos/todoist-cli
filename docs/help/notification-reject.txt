Usage:
  todoist notification reject [id] [--id <id>]

Flags:
  --id <id>                         ID

Global flags:
  -h, --help             Show help without running the command
  -n, --dry-run          Preview without Todoist mutations (reads may occur)
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Requires an ID from notification list. Rejects share_invitation_sent invitations only.

Examples:
  todoist notification reject --id 789
