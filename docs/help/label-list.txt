Usage:
  todoist label list [flags]

Aliases: ls

Flags:
  --cursor <cursor>                 Cursor
  --limit <n>                       Limit
  --all                             Fetch all pages

Global flags:
  -h, --help             Show help without running the command
  --no-input            Disable prompts
  --ids-only            Print one raw ID per result
  See 'todoist --help' for all global flags and output modes.

Notes:
  Use --all or the returned cursor for additional labels.

Examples:
  todoist label list --all --json
