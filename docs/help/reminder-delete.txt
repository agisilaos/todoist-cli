Usage:
  todoist reminder delete (<id> | --id <id>) [--yes]

Aliases: rm del

Flags:
  --id <id>                         Reminder ID
  --yes                             Skip confirmation

Global flags:
  -h, --help             Show help without running the command
  -n, --dry-run          Preview without Todoist mutations (reads may occur)
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Find reminder IDs with reminder list. Confirm using --yes, global --force, or an interactive prompt.

Examples:
  todoist reminder delete --id 678 --yes --dry-run
