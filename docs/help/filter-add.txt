Usage:
  todoist filter add --name <name> --query <query> [flags]

Flags:
  --name <name>                     Filter name
  --query <query>                   Filter query
  --color <color>                   Color
  --favorite                        Favorite

Global flags:
  -h, --help             Show help without running the command
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Quote Todoist queries to protect shell characters such as &.

Examples:
  todoist filter add --name "Work today" --query "@work & today"
