Usage:
  todoist project collaborators <id|name> [flags]

Flags:
  --id <id>                         Project ID or name
  --cursor <cursor>                 Cursor
  --limit <n>                       Limit
  --all                             Fetch all pages

Global flags:
  -h, --help             Show help without running the command
  --no-input            Disable prompts
  --ids-only            Print one raw ID per result
  See 'todoist --help' for all global flags and output modes.

Notes:
  Quote multiword names. Use --all or the returned cursor for more collaborators.

Examples:
  todoist project collaborators "Home" --json
