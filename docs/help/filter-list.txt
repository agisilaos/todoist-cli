Usage:
  todoist filter list

Aliases: ls

Flags:
  No command-specific flags.

Global flags:
  -h, --help             Show help without running the command
  --no-input            Disable prompts
  --ids-only            Print one raw ID per result
  See 'todoist --help' for all global flags and output modes.

Notes:
  Lists saved filters. Use filter show to list tasks matching a saved filter.

Examples:
  todoist filter list --json
