Usage:
  todoist stats goals [--daily <n>] [--weekly <n>]

Flags:
  --daily <n>                       Set daily goal
  --weekly <n>                      Set weekly goal

Global flags:
  -h, --help             Show help without running the command
  -n, --dry-run          Preview without Todoist mutations (reads may occur)
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Supply at least one non-negative goal. Use bare todoist stats to inspect productivity.

Examples:
  todoist stats goals --daily 5 --weekly 25 --dry-run
