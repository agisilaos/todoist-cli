Usage:
  todoist agent status

Flags:
  No command-specific flags.

Global flags:
  -h, --help             Show help without running the command
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Inspects local planner configuration and last-plan availability. Does not run the planner or apply a plan.

Examples:
  todoist agent status --json
