Usage:
  todoist task move <ref> [--project <ref>] [--section <ref>] [--parent <id>]
  todoist task move --filter <query> --yes [--project <ref>] [--section <ref>] [--parent <id>]

Flags:
  --id <id>                         Task ID
  --project <ref>                   Project
  --section <ref>                   Section
  --parent <id>                     Parent
  --filter <query>                  Filter query for bulk move
  --yes                             Required for bulk move

Global flags:
  -h, --help             Show help without running the command
  -n, --dry-run          Preview without Todoist mutations (reads may occur)
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Supply a destination. Use id:<id> for an exact task; use task list to resolve ambiguous references.
  Bulk selection uses --filter and requires --yes (or global --force); plain text filters become search text.

Examples:
  todoist task move id:123456 --project Home
  todoist task move --filter "@work & overdue" --project Home --yes --dry-run
