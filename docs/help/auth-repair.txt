Usage:
  todoist auth repair

Flags:
  No command-specific flags.

Global flags:
  -h, --help             Show help without running the command
  --profile <name>      Select the credential profile
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Retries recognized interrupted credential transactions and pending cleanup.
  Preserve corrupt files for deliberate recovery; repair does not repair arbitrary corrupt data
  or access another configuration directory's native entries.

Examples:
  todoist --profile work auth repair
