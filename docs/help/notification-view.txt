Usage:
  todoist notification view [id] [--id <id>]

Flags:
  --id <id>                         Notification ID

Global flags:
  -h, --help             Show help without running the command
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Find IDs with notification list; an ID is required.

Examples:
  todoist notification view --id 789
