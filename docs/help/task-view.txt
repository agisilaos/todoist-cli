Usage:
  todoist task view <ref> [--full]
  todoist task view --id <id> [--full]

Aliases: show

Flags:
  --id <id>                         Task ID
  --full                            Show full task fields

Global flags:
  -h, --help             Show help without running the command
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Use id:<id> for an exact task or a quoted text reference. Use task list when a name is ambiguous.

Examples:
  todoist task view id:123456 --full
