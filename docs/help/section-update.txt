Usage:
  todoist section update --id <id> --name <name>

Flags:
  --id <id>                         Section ID
  --name <name>                     Section name

Global flags:
  -h, --help             Show help without running the command
  -n, --dry-run          Preview without Todoist mutations (reads may occur)
  --no-input            Disable prompts
  See 'todoist --help' for all global flags and output modes.

Notes:
  Requires a section ID from section list.

Examples:
  todoist section update --id 345 --name "Ready for review"
